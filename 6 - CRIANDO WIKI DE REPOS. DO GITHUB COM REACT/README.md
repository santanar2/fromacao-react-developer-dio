# 🔎 Wiki de Repositórios GitHub com React

Aplicação desenvolvida em **React JS** que permite buscar usuários do GitHub e visualizar seus repositórios públicos através da integração com a API oficial do GitHub.

Este projeto foi desenvolvido com foco em consolidar conhecimentos de consumo de APIs, gerenciamento de estado e construção de interfaces interativas.

---

## 🚀 Demonstração

A aplicação permite:

* Buscar usuários do GitHub
* Listar repositórios públicos
* Exibir informações dinâmicas
* Navegação simples e intuitiva

## ▶️ Como Executar o Projeto

Clone o repositório:

```bash
git clone https://github.com/santanar2/fromacao-react-developer-dio.git
```

Entre na pasta do projeto:

```bash
cd 6-CRIANDO-WIKI-DE-REPOS-DO-GITHUB-COM-REACT/trilha-react-desafio-2
```

Instale as dependências:

```bash
npm install
```

Execute:

```bash
npm start
```
