# ⚛️ Criando um Projeto React do Zero

Projeto desenvolvido com o objetivo de compreender o funcionamento interno de uma aplicação **React JS**, realizando a configuração manual da estrutura do projeto sem utilização de ferramentas automáticas de criação.

---

## 🚀 Objetivo

* Entender como funciona a estrutura de um projeto React
* Configurar manualmente dependências
* Compreender o processo de build e execução
* Trabalhar com componentes e renderização
* Desenvolver autonomia na criação de aplicações Front-end

---

## 🧠 Conceitos Trabalhados

* Configuração manual do ambiente React
* Estrutura de pastas
* Importação de bibliotecas
* Componentes funcionais
* JSX
* Renderização no DOM
* Organização de código

---

## 💻 Tecnologias Utilizadas

* React JS
* JavaScript
* HTML5
* CSS3
* Node.js
* NPM
* Git e GitHub

---

## ▶️ Como Executar o Projeto

Clone o repositório:

```bash
git clone https://github.com/santanar2/fromacao-react-developer-dio.git
```

Entre na pasta do projeto:

```bash
cd 4-CRIANDO-UM-PROJETO-REACT-DO-ZERO
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
npm start
```
