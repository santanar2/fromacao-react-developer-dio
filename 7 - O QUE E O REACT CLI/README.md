# ⚛️ O que é React CLI

Projeto desenvolvido com o objetivo de compreender o funcionamento das ferramentas de linha de comando (CLI) utilizadas na criação e gerenciamento de aplicações React.

---

## 🚀 Objetivo

* Entender o conceito de CLI no desenvolvimento Front-end
* Aprender como criar projetos React de forma automatizada
* Compreender a estrutura padrão gerada
* Executar e gerenciar aplicações em ambiente local
* Aumentar a produtividade no desenvolvimento

---

## 🧠 Conceitos Trabalhados

* React CLI
* Criação automatizada de projetos
* Estrutura padrão de aplicações React
* Execução de scripts NPM
* Organização de código
* Fluxo de desenvolvimento moderno

---

## ▶️ Como Executar o Projeto

Clone o repositório:

```bash
git clone https://github.com/santanar2/fromacao-react-developer-dio.git
```

Entre na pasta do projeto:

```bash
cd 7-O-QUE-E-O-REACT-CLI
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
npm start
```
